# Open Source Learning

## Giới thiệu

Repository này được tạo để tìm hiểu và chia sẻ kiến thức cơ bản
về phần mềm mã nguồn mở.

## Nội dung

- Khái niệm phần mềm mã nguồn mở
- Các giấy phép phổ biến: GPL, MIT, Apache
- Tìm hiểu hệ điều hành Linux
- Tìm hiểu Git và GitHub
- Thực hành với một chương trình Python đơn giản

## Lợi ích của mã nguồn mở

Mã nguồn mở giúp người dùng có thể nghiên cứu, sử dụng và phát triển
phần mềm theo các điều kiện của giấy phép. Cộng đồng có thể cùng nhau
sửa lỗi, cải tiến phần mềm và chia sẻ kiến thức.

## Mục đích của repository

Repository phục vụ việc học tập và chia sẻ kiến thức về mã nguồn mở.
Nội dung sẽ được cập nhật trong quá trình học.
